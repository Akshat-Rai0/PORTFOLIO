00 / Project definition

Akshat’s portfolio.

v1 · single-page React site · GitHub Pages

Who it is for

Owner: Akshat, third-year B.Tech student, Computer Science & Engineering (AI & ML), Birla Institute of Technology (BIT) Mesra, graduating 2028. Target track: Agentic AI.

Audience: recruiters and engineers scanning quickly. The site must prove he builds LLM agents that plan, execute, and retrieve — not a blog, not a CMS.

GitHub: github.com/Akshat-Rai0

Goals

  • Present a scannable, high-contrast dark portfolio that looks like an agent runtime, not a generic student template.
  • Keep all project and skill content data-driven so adding work is a one-file edit.
  • Ship to GitHub Pages with a configurable Vite base.
  • Honor reduced motion, keyboard access, and WCAG AA on black.
  • Deliver a reusable case-study HTML template for later per-repo GitHub Pages.

Scope (v1)

In scope: a single-page React site with sections in this order: Hero, About (agent trace), Stack (3-row skills banner), Work (Flex Carousel of projects), Contact. Resume button, phone fallback (static hero + stacked layout under 768px), data-driven projects and skills, reduced-motion support, GitHub Pages deploy, and a reusable case-study page template (static HTML/CSS/JS).

Out of scope

  • Blog, CMS, or any backend
  • Contact-form backend (links only)
  • Light/dark theme toggle
  • Lenis or any scroll hijacking
  • Analytics and i18n
  • Filled case-study content (template only)

Success criteria (definition of done)

  • All five docs exist in /docs.
  • The site builds, runs, and visually matches the design tokens and section layouts.
  • Terminal plays once on scroll; reduced-motion shows it instantly.
  • Exactly 6 skill tiles visible per row on desktop (3 on mobile); rows loop seamlessly.
  • Only the center project card plays video.
  • Adding a project or skill requires editing only a data file.
  • Phone (<768px) shows the static bird fallback; Vanta/Three are not downloaded.
  • Deploys to GitHub Pages through the included workflow.

Filename kept as project_difination.html per build prompt.
