01 / Behavior

How it should work.

Every interaction is written as “when X happens, Y occurs.” Native scroll only. No Lenis. GSAP for motion unless CSS is specified.

6.1 Hero + Vanta

WHEN the page loads on a viewport ≥ 768px, motion is allowed, and WebGL exists, THEN Vanta BIRDS is created on the hero with the exact config (red/teal birds on black), and THREE r134 is passed in.
WHEN the component unmounts or StrictMode remounts, THEN effect.destroy() always runs so canvases do not stack.
WHEN the hero leaves the viewport, THEN the Vanta effect is destroyed (GPU free for the carousel). WHEN it returns, THEN the effect is recreated.
WHEN viewport < 768px, or prefers-reduced-motion: reduce, or WebGL is missing, THEN no Vanta/Three chunk is downloaded; a static SVG scatter of ~16 chevrons is shown instead.
WHEN the user clicks About / Work / Contact, THEN the page smooth-scrolls to that section (GSAP ScrollTo, or native if reduced motion).
WHEN the user clicks See my projects, THEN scroll goes to #work. GitHub opens the profile. Resume opens resumeUrl in a new tab with rel="noopener noreferrer".

6.2 Section reveals

WHEN a section’s top hits 80% of the viewport, THEN its label and main content fade/translate in (opacity 0→1, y 32→0, 0.7s, power3.out), once. No pin, no scrub, no reverse.
WHEN the hero loads, THEN hero copy staggers in at 0.1s. WHEN reduced motion is on, THEN content is visible immediately.

6.3 Agent trace

WHEN the terminal’s top reaches 60% of the viewport, THEN a one-shot GSAP timeline plays: command types in; three PLAN lines appear (~0.45s apart); 0.7s pause; three EXECUTE lines with ✓ pop; short pause; RESULT types ~25ms/char; teal cursor blinks.
WHEN the timeline has not fired, THEN lines stay in layout (opacity/visibility, never display:none) so the card does not resize.
WHEN reduced motion is on, THEN every line is shown instantly, no typing. WHEN JS is disabled, THEN lines are visible in the HTML.
WHEN projects.js length changes, THEN the EXECUTE line shows that count dynamically.

6.4 Work carousel

WHEN projects load, THEN they come only from src/data/projects.js. A mapping layer converts each project into the card shape the carousel expects. Missing media or pagesUrl never crashes. Duplicate/missing ids warn in development.
WHEN the user drags, swipes, uses prev/next, wheels with horizontal intent, or presses Left/Right while the stage is focused, THEN the active index wraps infinitely and an aria-live region announces the change.
WHEN the center index changes, THEN the previous <video> is paused and unmounted; only the new center card may mount a muted, looping, playsInline, autoPlaying video. Other cards show poster (or gradient) only.
WHEN reduced motion is on, THEN videos do not autoplay; posters show.
WHEN pagesUrl is empty, THEN the live link is a disabled “Coming soon” pill. Otherwise it opens in a new tab.

Stack marquee

WHEN the row is idle, THEN the duplicated track translates 0 → −50% (row 2 reversed), looping. WHEN the user hovers or focus is inside a row, THEN animation pauses. WHEN reduced motion is on, THEN rows become a static wrapping grid.

Focus, keyboard, reduced motion (global)

WHEN any control is focused from the keyboard, THEN a visible teal focus ring appears.
WHEN prefers-reduced-motion: reduce, THEN Vanta is skipped, marquees stop, traces and reveals are instant, and video does not autoplay.
