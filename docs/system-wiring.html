04 / Architecture

System wiring.

Component tree

Data flow

site.js        → Hero, Nav, Contact (handle, github, email, linkedin, resumeUrl)
projects.js    → About (length), Work → mapToFlexItems() → FlexCarousel / ProjectCard
skills.js      → Stack → SkillRow → SkillTile (simple-icons path or monogram)
validateProjects() logs in DEV only; missing video/poster/pagesUrl is safe

GSAP lifecycle

Register ScrollTrigger + ScrollToPlugin once. Every animated section uses useGSAP({ scope }) so triggers revert on unmount. Hero content tweens on load. Section reveals: start: "top 80%", once. Agent trace: start: "top 60%", once, never reversed. After document.fonts.ready, call ScrollTrigger.refresh().

WebGL lifecycle

Vanta BIRDS is dynamically imported only when fallback is false. Create in effect; always destroy on cleanup. Destroy when hero leaves view; recreate on enter back. Never import three except that chunk, pinned at 0.134.0. FlexCarousel uses ogl (not Three). If FlexCarousel is active, Vanta must already be destroyed. Reduced-motion / mobile / no WebGL: StaticBirds, no Three download.

Deploy pipeline

git push main
  → .github/workflows/deploy.yml
  → if repo == <user>.github.io then VITE_BASE=/ else VITE_BASE=/<repo>/
  → npm ci && npm run build
  → upload dist as Pages artifact
  → deploy-pages
